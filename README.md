# The Journey Journal — Pynexia Week 3 Assignment 1

A responsive editorial blog platform built with HTML, CSS Grid, and JavaScript.

## Files
- `index.html` — page structure and article content
- `style.css` — editorial styling and responsive layouts
- `script.js` — category filters, mobile navigation, and newsletter form feedback

## Run locally
Open `index.html` in a browser.

## Notes
The newsletter form demonstrates client-side validation and feedback. It does not store or send email addresses because no backend service is connected.
